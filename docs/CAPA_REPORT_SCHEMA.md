# CAPA Report Schema

CAPA (Corrective and Preventive Action) reports generated by this system are aligned with:
- **ICH E6(R2)** Section 5.20 — Protocol Deviation Management
- **FDA 21 CFR Part 312** — IND regulations
- **ISO 9001:2015** — CAPA framework principles

---

## Top-Level Report Object

```typescript
interface CAPAReport {
  reportId: string;          // e.g. "CAPA-RPT-0001"
  generatedAt: string;       // ISO 8601 timestamp
  protocolId: string;        // e.g. "PROT-2024-001"
  siteId: string;            // e.g. "SITE-042"
  findings: CAPAFinding[];   // One per deviation
  executiveSummary: string;  // Narrative summary for regulatory submission
  overallSiteRisk: SiteRiskScore;
}
```

---

## Finding Object

```typescript
interface CAPAFinding {
  findingId: string;                   // e.g. "CAPA-FND-000001"
  deviation: ProtocolDeviation;        // The underlying deviation (ICH E6 classified)
  rootCauseCategory: RootCauseCategory; // "system" | "process" | "training" | "communication"
  rootCauseDescription: string;        // Detailed narrative
  correctiveActions: CAPAAction[];     // Immediate actions
  preventiveActions: CAPAAction[];     // Systemic improvements
  responsibleParty: string;            // PI / CRA / Coordinator
  effectivenessCheck: string;          // How to verify the CAPA worked
}
```

---

## Action Object

```typescript
interface CAPAAction {
  actionId: string;          // e.g. "CAPA-ACT-000001"
  description: string;       // Full text of the action
  dueDate: string;           // ISO 8601 date (tiered by severity)
  priority: "immediate" | "short_term" | "long_term";
}
```

---

## ICH E6 Due Date Tiers

| Severity | Corrective Actions | Preventive Actions |
|---|---|---|
| Major | Within **7 days** | Within **30 days** |
| Minor | Within **14 days** | Within **60 days** |
| Administrative | Within **30 days** | Within **90 days** |

---

## Root Cause Categories

| Category | Typical Triggers |
|---|---|
| **System** | Eligibility violations, EDC misconfiguration |
| **Process** | Missed visits, window deviations, missing procedures |
| **Training** | Wrong dosing, banned co-medication |
| **Communication** | Documentation gaps, missing assessments |

---

## Responsible Party Assignment

| Severity | Responsible Party |
|---|---|
| Major | Principal Investigator + Sponsor Medical Monitor |
| Minor (documentation) | Clinical Research Associate (CRA) |
| Minor / Administrative | Site Coordinator + Principal Investigator |
